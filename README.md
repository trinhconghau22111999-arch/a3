# ScreenCast – chiếu màn hình điện thoại lên TV qua WiFi (WebRTC)

Màn hình chính: bấm "Bắt đầu chiếu", rồi mở địa chỉ hiện ra trên trình duyệt TV.
Nút "Mở Tube for me": app con (trình duyệt YouTube) nằm ngay trong app này.

Build: đẩy lên GitHub, tab Actions → Build APK, hoặc tải trong mục Releases.
