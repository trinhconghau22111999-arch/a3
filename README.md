# ScreenCast – chiếu màn hình điện thoại lên TV qua WiFi (WebRTC)

1. Đẩy toàn bộ thư mục này lên GitHub (nhánh main).
2. Vào tab Actions → chạy "Build APK" → tải file `ScreenCast-apk` (app-debug.apk).
3. Cài APK lên điện thoại, mở app, bấm "Bắt đầu chiếu".
4. Trên TV mở trình duyệt, gõ địa chỉ app hiện ra (ví dụ http://192.168.1.5:8080).

Không cần tài khoản, không cần Internet, không cần Firebase.
